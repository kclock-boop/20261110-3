주간 공지 자동등록 도우미 / Windows PC용

현재 상태
- 공지 편집·예약·브라우저 입력·등록·중복 방지 기능을 구현했습니다.
- 예약·중복 방지 로직은 검증했습니다. 회사 게시판 연결은 아직 설정되지 않았습니다.
- 회사 게시판 주소와 화면 구조가 없으므로 다운로드만으로 회사 게시판에 자동 등록되지는 않습니다.
- 일반적인 제목 입력칸 + 본문 입력칸/편집 가능 영역 + 등록 버튼 구조를 지원합니다.
- 본문 iframe 하나는 지원합니다. 다중 프레임·팝업형 편집기·첨부파일·별도 확인창·CAPTCHA 등은 회사별 추가 작업이 필요합니다.

1. 처음 실행
① ZIP 파일에서 '모두 압축 풀기'를 선택합니다.
② PC에 Python 3.10 이상이 설치되어 있어야 합니다. 없으면 회사 전산 담당자에게 설치를 요청하세요.
③ 1_install.bat 파일을 더블클릭합니다. 최초 1회 인터넷 연결이 필요합니다.
④ 설치 완료 후 2_start.bat 파일을 더블클릭합니다.
※ 설치 완료 전에는 시작되지 않습니다. Python 설치형 프로그램이며 독립 실행 EXE가 아닙니다.

2. 먼저 연습해 보기 (회사에 게시하지 않음)
① 3_demo.bat 파일을 실행하고 검은 창을 열어 둡니다.
② 2_start.bat 실행 후 아래 값을 입력합니다.
글쓰기 페이지 주소: http://127.0.0.1:8765/demo.html
공유폴더 주소: 연습용 폴더
제목 입력 요소: #title
본문 입력 요소: #body
등록 버튼 요소: #submit
등록완료 표시 요소: #success
글쓰기 iframe 요소: 빈칸
③ '③ 입력 시험'을 누릅니다. 시험용 페이지의 제목과 내용이 채워집니다.
등록 버튼은 자동으로 누르지 않습니다. 확인 후 해당 브라우저 창을 닫습니다.
④ '④ 지금 1회 등록'을 누르면 확인창이 나옵니다. 동의하면 시험용 게시판에 등록합니다.
등록완료 표시가 나타나면 성공입니다. 시험용 게시판은 새로고침 시 초기화됩니다.
※ 시험 게시도 오늘의 중복 방지 기록에 포함됩니다. 실제 회사 첫 게시 시험은 다른 날 진행하거나,
모든 창을 닫고 시험 폴더와 분리한 새 압축 해제 폴더에서 진행하세요.

3. 회사 게시판 연결 (처음 1회 전산 담당자와 함께 설정 권장)
① 공지를 쓰는 화면의 주소를 입력합니다. 회사 게시판 목록 주소가 아닌 '글쓰기' 주소입니다.
② '① 로그인'을 누르고 열린 브라우저에서 직접 로그인합니다.
로그인 후 브라우저 창을 닫습니다. 비밀번호를 프로그램 설정에 입력하지 않습니다.
③ '② 요소 찾기'를 누릅니다. Playwright 검사 창에서 Pick locator를 켜고
제목 입력칸, 본문 입력칸, 등록 버튼을 각각 선택합니다.
검사 창의 locator 문자열만 해당 설정칸에 복사합니다.
예: #title 또는 input[name="subject"] 또는 role=button[name="등록"]
page.locator(...) 같은 Python 코드 전체는 붙여넣지 않습니다.
Resume으로 검사 작업을 마친 후 프로그램으로 돌아옵니다.
④ 등록 후에만 표시되는 성공 메시지나 게시물 상세 화면의 고유 요소도 지정합니다.
예: .notice-save-success 또는 #article-detail
제목/본문과 등록 버튼은 iframe 설정이 있으면 그 안에서 찾습니다.
등록완료 표시는 최상위 화면에서 찾습니다. 필요한 경우 iframe >> ... 형태 대신
회사 화면에 맞춰 추가 개발이 필요할 수 있습니다.
⑤ 실제 공지에 넣을 공유폴더 주소를 입력합니다.
⑥ 예약은 꺼 둔 채 '③ 입력 시험'으로 내용과 대상 게시판을 확인합니다.
⑦ '④ 지금 1회 등록'으로 게시를 시험하고 실제 게시판에서 결과를 확인합니다.
확인창이 추가로 나오거나 등록 후 완료 표시를 찾지 못하면 자동으로 재시도하지 않습니다.
실제 게시물을 먼저 확인하고 회사별 설정을 보완해야 합니다.
※ 성공 메시지가 항상 떠 있는 요소라면 등록 전 검증에서 차단됩니다.

4. 매주 자동 등록
- 기본 예시: 매주 금요일 오전 09:00, 예약은 꺼짐.
- 원하는 요일과 시각(HH:MM, 한국시간)을 설정합니다.
- 내용의 {폴더}는 입력한 공유폴더 주소로, {날짜}는 게시일로 바뀝니다.
- '예약 자동 게시 켜기'를 선택하고 '설정 저장'을 누릅니다.
- 프로그램을 켜 둡니다. 창을 최소화해도 되지만 종료하면 예약은 멈춥니다.
- PC가 꺼져 있거나 절전 상태이거나 VPN/인터넷이 끊기면 게시할 수 없습니다.
- 예약 시각의 해당 1분 안에서만 실행하며 놓친 공지를 나중에 자동 게시하지 않습니다.
- 로그인 세션이 만료되면 '① 로그인'으로 다시 로그인해야 합니다.
- 입력 시험 등 다른 작업 중이면 예약 시도는 건너뛰며 자동 재시도하지 않습니다.
- Windows 시작 시 자동 실행하거나 PC가 꺼져 있어도 게시하는 기능은 포함하지 않았습니다.

5. 중복 방지·실패 확인
- 날짜 기준 하루 1회만 실제 게시를 시도합니다. 수동 게시와 예약 게시가 같은 기록을 사용합니다.
- 성공 여부가 불확실한 경우도 같은 날 재시도하지 않습니다.
- 기록은 history.db에 남습니다. 프로그램 아래 화면에 이번 실행 로그가 표시됩니다.
- 등록 버튼을 누른 직후 인터넷이 끊기면 실제 등록되었어도 '확인 필요'로 기록될 수 있습니다.
- 이때 게시판을 직접 확인해야 합니다. 기록 삭제나 반복 클릭은 중복 게시를 만들 수 있습니다.
- 설정 변경만으로 오늘의 게시 시도 기록이 초기화되지는 않습니다.
- 여러 PC/여러 압축 해제 폴더에서 동시에 예약하지 마세요. 중복 방지는 같은 폴더 내에서 작동합니다.

6. 보관 파일
settings.json: 제목, 내용, 예약 시각, 게시판 연결 설정.
history.db: 날짜별 실행 결과. SQLite 뷰어가 있는 전산 담당자가 확인할 수 있습니다.
browser_profile 폴더: 로그인 세션. 다른 사람에게 전달하거나 압축해서 공유하지 마세요.
프로그램 폴더는 본인 PC의 접근 제한된 위치에서 사용하세요.
외부 AI 서버나 별도 클라우드 서버로 공지 내용을 보내는 코드는 없습니다.
브라우저는 설정한 회사 게시판에 연결합니다.

7. 회사 연결을 마무리하려면
제작자에게 그룹웨어 이름/글쓰기 화면 주소, 원하는 게시 요일·시각,
공유폴더 주소, 제목·본문·등록 버튼이 보이는 화면을 알려주세요.
비밀번호와 로그인 세션은 전달하지 마세요.

검증 범위
- 한국시간 요일/시각 판정, 예약 꺼짐, 누락 시각 미실행
- 날짜별 중복 실행 차단 및 실패 후 자동 재시도 방지
- 미설정 게시 대상 차단
- 브라우저 통합 시험 코드는 포함했으나 현재 제작 환경에서 브라우저 프로세스 실행이 제한되어
  제목/본문 입력·실제 등록·완료 표시 검증은 실행하지 못했습니다.
- 시험용 HTML 게시판을 포함했으므로 설치 후 2번 절차로 확인할 수 있습니다.
실제 회사 그룹웨어 및 Windows PC에서의 설치·GUI 실행은 아직 검증하지 않았습니다.
